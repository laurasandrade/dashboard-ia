# PRD: DORA Copilot

> Rascunho inicial. Reescreva cada campo com a sua voz e os seus números.

| Item | Seu texto |
|---|---|
| **Problema** | Líderes de engenharia gastam horas toda semana juntando métricas de entrega e explicando-as para a diretoria. |
| **Persona** | Engineering Manager / Delivery Manager de 3 a 6 times, que precisa reportar evolução e riscos ao C-level. |
| **Hipótese** | Um copiloto que responde em linguagem natural e gera o resumo semanal reduz o tempo de preparação do report em mais de 70%, sem perder confiabilidade. |
| **Métricas de sucesso** | Acerto ≥ 85% no dataset de avaliação; custo por consulta < R$ 0,05; tempo de report de 2h para 15 min; 0 números inventados. |
| **MVP** | Dashboard com 4 métricas DORA por time e período, chat com tool calling e resumo semanal. |
| **Fora do MVP** | Integração real com Jira, alertas proativos, multi-tenant. |

## Priorização (RICE)

1. Dashboard + chat com tools
2. Resumo semanal
3. RAG
4. Alertas
